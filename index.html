How to use this page
  1. Type one or more words and press Search. Several words must appear close together and in that order (negro woman finds "a Negro Woman named Jane").
  2. Each result shows the date, the newspaper, the page, the text read by the computer, and — where available — a picture of the printed notice with the words marked in red.
  3. The computer's reading of the old print contains errors. Always trust the picture over the text. Open the page at the Royal Library shows the whole original page. If the text is wrong, click Correct OCR, type what the print actually says, and save. Your correction is stored in this browser and included when you download; it does not change the search.
  4. For each result, click Yes if it describes a woman, No if it does not, or Unsure; add a note if you like.
  5. Download this list saves a spreadsheet of every hit, including the computer’s OCR text. Where a picture of the notice exists, the download is a zip folder with those pictures as well.
  6. Results are listed in date order (oldest first). Use Sort to switch to newest first, or to the computer's best-match order.
  7. Put = before a word to turn off variant spellings for that word only (=woman will not also find Roman).

Pictures are shown for passages found by the project's list of words for women; for other searches, use the Royal Library link.
